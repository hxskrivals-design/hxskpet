# 🚀 Auto-Deploy Guide for hxskpet

## Deploy in 2 clicks (seriously!)

### **Step 1: Deploy Frontend to Vercel**
1. Go to https://vercel.com/import
2. Click "Import Git Repository"
3. Select `hxskpet` 
4. **Root Directory**: Set to `frontend`
5. Click "Deploy" 
6. **DONE!** ✅ Your site is live!

**You'll get:** `https://hxskpet.vercel.app`

---

### **Step 2: Deploy Backend to Render**
1. Go to https://render.com
2. Click "New +" → "Web Service"
3. Select `hxskpet` repo
4. **Root Directory**: `api`
5. **Build Command**: `npm install`
6. **Start Command**: `npm start`
7. Click "Create Web Service"
8. **DONE!** ✅ API is live!

**You'll get:** `https://hxskpet-api.onrender.com`

---

### **Step 3: Update Config (Optional)**
Tell me your Render API URL and I'll update your frontend config to use it.

That's it! Your site is deployed! 🎉
